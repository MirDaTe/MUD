## 🌸 프로젝트 개요

**낙화검심(落花劍心)** 은 웹 브라우저에서 즐기는 **정통 무협 멀티플레이 MUD**입니다.
김용풍 무협의 낭만과 비극미를 현대 웹 기술로 재해석한 독자 세계관의 온라인 RPG입니다.

> **"문장을 읽는 순간 장면이 떠오르고, 명령을 입력하는 순간 운명이 갈리는 정통 무협 멀티플레이 MUD"**

### 핵심 콘셉트
- 이름 없는 소협으로 시작하여 강호의 비전무공과 음모 속에서 성장
- 미녀 협객들과 인연을 쌓고, 문파와 세력의 갈등 속에서 선택
- 천하제일의 영웅 또는 공포의 패왕으로 거듭나는 다중 엔딩

### 게임 스케일 (Mega v0.3.0)
| 항목 | 수량 |
|------|------|
| 🏠 **지역/방** | **72개 방** / 12개 지역 |

| 👥 **연애 대상** | **8명** (설매화·연비홍·묵련·소하린·담월·유하영·홍소월·백리연) |

| 🐉 **몬스터** | **83종** |

## 💎 강화(Inchant) 시스템

### 개요
아이템을 **+0에서 +15까지** 강화하여 성능을 극대화합니다.

### 강화 명령어
```bash
enchant <아이템명>              # 기본 강화
enchant <아이템명> -p           # 보호석 사용 (실패 시 레벨 유지)
enchant <아이템명> -a           # 고급강화석 사용 (성공률 +20%)
enchant <아이템명> -p -a        # 둘 다 사용
```

### 강화 재료
| 재료 | 효과 | 획득처 |
|------|------|--------|
| **강화석** | 기본 강화 재료 (1~10개 소모) | 상점·몬스터 드랍 |
| **보호석** | 실패 시 아이템 레벨 보호 | 암시장·보스 드랍 |
| **고급강화석** | 성공률 20% 상승 | 보스 드랍·이벤트 |
| **축복의서** | 성공 시 2단계 상승 확률 | 희귀 이벤트 |
| **수호부적** | 실패 횟수 초기화 | 특수 퀘스트 |

### 강화 단계별 성공률 & 스탯 보너스

| 레벨 | 성공률 | 무기(공격) | 방어구(방어) | 장신구(HP) |
|------|--------|-----------|-------------|-----------|
| +0→+1 | 90% | +2 | +1 | +1 |
| +3→+4 | 75% | +8 | +4 | +4 |
| +7→+8 | 55% | +19 | +11 | +10 |
| +10→+11 | 40% | +30 | +19 | +14 |
| +14→+15 | 25% | +52 | +35 | +31 |

## 🚀 설치 및 구동 방법

### 1️⃣ 소스 코드 다운로드
```bash
git clone https://github.com/MirDaTe/MUD.git
cd MUD
```

### 2️⃣ 패키지 설치
```bash
pip install -r requirements.txt
```

### 3️⃣ 데이터베이스 초기화 (6개 시드)
```bash
cd backend
python3 seed.py              # 기본
python3 seed_extended.py     # 확장 맵/NPC/몬스터
python3 seed_martial_arts.py # 무공 210종
python3 seed_items.py        # 아이템 100종
python3 seed_factions.py     # 문파 10개
python3 seed_shops.py        # 상점 3곳
python3 seed_mega_rooms.py   # Mega 방 50개
python3 seed_mega_npcs.py    # Mega NPC 50명
python3 seed_mega_monsters.py # Mega 몬스터 58종
python3 seed_mega_items.py   # Mega 아이템 241종
python3 seed_mega_shops.py   # Mega 상점 10곳
```

### 4️⃣ 서버 실행
```bash
cd backend
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 5️⃣ 프론트엔드 실행 (새 터미널)
```bash
cd frontend
python3 -m http.server 8080
```

접속: **http://localhost:8080**

## 🕹 플레이 명령어

| 명령어 | 동작 |
|--------|------|
| `look` / `보기` | 현재 위치 살펴보기 |
| `북` `남` `동` `서` `up` `down` `enter` | 방향 이동 (지역마다 출구 다름) |
| `attack <대상>` | 기본 공격 |
| `cast <무공명>` | 무공 발동 |
| `meditate` / `수련` | 내공 운행 |
| `talk <대상>` | NPC와 대화 |
| `status` / `상태` | 캐릭터 정보 |
| `inv` / `가방` | 소지품 확인 |
| `equip <아이템>` | 장비 장착 |
| `use <아이템>` | 소모품 사용 |
| `arts` / `무공목록` | 배운 무공 확인 |
| `quest` / `퀘스트` | 진행 중인 의뢰 |
| `shop` / `상점` | 상점 물품 보기 |
| `buy <아이템>` | 구매 |
| `enchant <아이템명> [-p] [-a]` | 아이템 강화 (+1~+15) |
| `save` / `저장` | 수동 저장 |
| `help` / `도움` | 도움말 |
