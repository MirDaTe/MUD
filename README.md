## 🌸 프로젝트 개요

**낙화검심(落花劍心)** 은 웹 브라우저에서 즐기는 **정통 무협 멀티플레이 MUD**입니다.
김용풍 무협의 낭만과 비극미를 현대 웹 기술로 재해석한 독자 세계관의 온라인 RPG입니다.

> **"문장을 읽는 순간 장면이 떠오르고, 명령을 입력하는 순간 운명이 갈리는 정통 무협 멀티플레이 MUD"**

### 핵심 콘셉트
- 이름 없는 소협으로 시작하여 강호의 비전무공과 음모 속에서 성장
- 미녀 협객들과 인연을 쌓고, 문파와 세력의 갈등 속에서 선택
- 천하제일의 영웅 또는 공포의 패왕으로 거듭나는 다중 엔딩

### 감성 키워드
`비애` `낭만` `검기` `강호` `의리` `배신` `수련` `인연` `혈전` `무림비사` `벚꽃` `잔향`

## 🎮 게임 특징

### 🌏 세계관 — 유화중원
- **시대:** 가상의 중원 (실존 왕조 미사용)
- **중심 소재:** 칠분된 전설의 비급 **"낙화검결"**
- **흑막 세력:** 정체불명의 조직 **"귀화천(鬼花天)"**

### ⚔️ 무공 시스템
| 항목 | 내용 |
|------|------|
| 무공 종류 | **210종** (검법·도법·장법·권법·지법·암기·경공·호신강기·내공심법·진법·독공·악기공) |
| 경지 체계 | **9단계** (입문→소성→대성→원만→절정→초절정→화경→현경→신화경) |
| 전투 시스템 | 틱 기반 실시간 전투 (치명타/회피/반격/DOT/버프/디버프) |
| 성장 시스템 | 전투 승리 시 숙련도 상승 → 경험치 누적 → 경지 돌파 |

### 🏯 문파 & 세력 (10개)
| 분류 | 문파명 | 특징 |
|------|--------|------|
| **정파** | 청람검문 | 절제된 검식, 방어/반격 특화 |
| **정파** | 운소궁 | 경공·기공, 여성 고수 다수 |
| **정파** | 백운서원 | 유생형 무공, 기문진법 |
| **사파** | 혈하문 | 출혈·흡혈·광폭화 |
| **사파** | 야명곡 | 독공·암습·환술 |
| **마도** | 흑련교 | 내공오염·제어·집단의식 |
| **중립** | 유성상단 | 거래·정보·장비조달 |
| **중립** | 무명각 | 암살·의뢰·현상금 |
| **중립** | 금풍표국 | 호송·호위·평판 |
| **특수** | 황영사 | 황실 첩보기관 |

### 👤 캐릭터 생성
- **6가지 출신:** 떠돌이 고아 / 몰락세가 후예 / 하급 문파 외문제자 / 상단 호위무사 / 관가 추방검객 / 의문의 기억상실자
- **6가지 자질:** 근골(외공) · 기맥(내공) · 신법(회피/속도) · 심안(치명타/간파) · 매력(NPC 호감도) · 복운(희귀 이벤트)

### 💕 연애 시스템
- **5명의 연애 가능 NPC:** 설매화·연비홍·묵련·소하린·담월
- 호감도 7단계: 경계 → 관심 → 신뢰 → 의지 → 연모 → 맹약 → 비극/파멸/결별 분기
- 선물·대화 선택·전투 지원·사건 개입으로 호감도 변동

### 🎯 플레이 성향
- **6축 성향:** 의(義)·협(俠)·욕(慾)·냉(冷)·광(狂)·정(情)
- 성향에 따라 NPC 대사·연애 가능 인물·무공 적합도·세력 호감도·엔딩 변경

## 🚀 설치 및 구동 방법

### 사전 요구사항
- **Python 3.9 이상**
- **pip** (Python 패키지 관리자)
- **Git** (소스 코드 클론)

### 1️⃣ 소스 코드 다운로드

```bash
git clone https://github.com/MirDaTe/MUD.git
cd MUD
```

### 2️⃣ Python 패키지 설치

```bash
pip install -r requirements.txt
```

> ⚠️ `pip` 명령이 없다면 `pip3` 또는 `python3 -m pip` 사용

### 3️⃣ 데이터베이스 초기화 (시드 데이터 생성)

```bash
cd backend

# 순서대로 실행 (약 3~5초 소요)
python3 seed.py              # 기본 5개 방, 3명 NPC, 5종 몬스터
python3 seed_extended.py     # 17개 방, 17명 NPC, 20종 몬스터 + 5종 보스
python3 seed_martial_arts.py # 무공 210종
python3 seed_items.py        # 아이템 100종
python3 seed_factions.py     # 문파/세력 10개
python3 seed_shops.py        # 상점 3곳
```

> 💡 이미 시드된 상태면 각 스크립트가 자동으로 스킵합니다.

### 4️⃣ 백엔드 서버 실행

```bash
cd backend
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

- 서버 주소: `http://localhost:8000`
- API 문서: `http://localhost:8000/docs` (Swagger UI 자동 생성)
- 헬스체크: `http://localhost:8000/api/health`

### 5️⃣ 프론트엔드 서버 실행

```bash
# 새 터미널에서
cd frontend
python3 -m http.server 8080
```

- 게임 접속: `http://localhost:8080`

## 🕹 플레이 방법

### 처음 접속
1. 브라우저에서 `http://localhost:8080` 접속
2. **회원가입** (이름 + 이메일 + 비밀번호)
3. **캐릭터 생성** (이름 + 출신 선택 + 자질 분배)
4. 강호 입문! 🗡️🌸

### 게임 명령어

| 명령어 | 동작 |
|--------|------|
| `look` / `보기` | 현재 위치 살펴보기 |
| `북` `남` `동` `서` | 방향 이동 |
| `attack <대상>` | 기본 공격 |
| `cast <무공명>` | 무공 발동 (예: `cast 낙화십이검`) |
| `meditate` / `수련` | 내공 운행 (MP·EXP 회복) |
| `talk <대상>` | NPC와 대화 |
| `status` / `상태` | 캐릭터 정보 보기 |
| `inv` / `가방` | 소지품 확인 |
| `equip <아이템>` | 장비 장착 |
| `use <아이템>` | 소모품 사용 |
| `arts` / `무공목록` | 배운 무공 목록 |
| `quest` / `퀘스트` | 현재 의뢰 확인 |
| `shop` / `상점` | 상점 물품 보기 |
| `buy <아이템>` | 아이템 구매 |
| `save` / `저장` | 수동 저장 (자동 저장도 지원) |
| `help` / `도움` | 도움말 |

### UI 구성
| 영역 | 내용 |
|------|------|
| **좌측 패널** | 캐릭터 상태 (HP/MP 바, 경지, 레벨, 자질) |
| **중앙 화면** | 메인 텍스트 로그 + 명령 입력창 |
| **우측 패널** | 강호채팅 / 주변인물 / 명령어 탭 |
| **상단 바** | 게임명, 현재 지역, 접속 상태 |

## 📝 API 문서

## 🏆 밸런스 & 철학

### 핵심 개발 원칙
- **텍스트 = 그래픽** — 서술 퀄리티가 곧 게임의 품질
- 모든 지역·무공·NPC는 기억에 남을 것
- 단순 반복 퀘스트 지양, 선택과 결과 중심 설계
- 전투·이동·대화·연애·배신·문파 정치가 살아있는 강호

### 전투 문체 원칙
- 일반 공격: 간결하고 냉철하게
- 치명타/절기: 화려하고 폭발적으로
- 피격/사망: 잔혹미와 비장미를 담아
- 같은 기술도 성공/막힘/치명타/역습에 따라 문장 변화

### 밸런스
- 과금형 P2W 금지
- 무공 간 상성 존재
- 특정 문파 압도 금지
- 초반 빠른 성장 → 중반 빌드 다양성 → 후반 숙련 중심
