# ⚔️ 낙화검심 (Nakhwa Geomshim) v0.6.0

> **귀환과 장비의 시대** — MMO급 13슬롯 장비·귀환·대규모 월드 확장

무협 텍스트 기반 MMORPG 백엔드 서버입니다.  
FastAPI + SQLAlchemy + SQLite 기반의 REST API & WebSocket 실시간 게임 시스템.

## ⚙️ 시스템 요약

### v0.1~v0.4 (기초)
- JWT 인증, 캐릭터 생성 (6종 출신)
- 방 이동 (동서남북/위/아래), NPC 대화, 상점
- 전투 (기본 공격 + 치명타), 몬스터
- 무공 210종 + 경지 시스템 (9단계)
- 퀘스트, 세력, 호감도, 강화 (+15)

### v0.5.0 — 문파의 탄생
- 🏯 길드 (문파) 생성/가입/승인/탈퇴/추방/계급(5단계)
- 🏆 명성 버프 7단계 마일스톤 (최대 공+160/방+100/HP+5000)
- 📦 길드 창고 (보관/인출), 💰 길드 금고 (입금/출금)
- 🛒 판매(반값)/분해(강화석)/버리기
- 📈 레벨 999 확장 (지수함수 EXP)

### v0.6.0 — 귀환과 장비의 시대 ✨
- 🎒 **13슬롯 장비** — WoW 스타일 장비창 (머리/가슴/바지/신발/장갑/망토/목걸이/반지2/속옷/장신구2/주무기/보조무기)
- ⚔️ **양손무기**: 장착 시 보조무기 자동 해제
- 🏠 **귀환 시스템**: 지역별 여관 지정 → 귀환서/마을귀환서/고급귀환서
- 💰 **돈 상한**: 9,999,999,999 은전
- 📦 **소모품 중첩 100개**, 장비 중첩 불가
- 🏠 **방 151개**: 8개 신규 지역 (황룡산맥/폭풍해안/지하수로/비취정원/마법탑/고대유적/암흑숲/운룡협곡)
- 📦 **아이템 531종**: 고유 코드(code) + 장비 인스턴스 UUID
- 👹 **몬스터 88종**: 레벨제 드롭테이블 (인챈트 재료는 모든 몬스터가 드랍, 레벨↑ 확률↑)
- 🛡️ **관리자**: 아이템 검색/상세/코드 지급, 방 필터링 (안전/여관)

## ⌨️ 명령어

### 🎮 기본
| 명령어 | 예시 | 설명 |
|--------|------|------|
| `look`, `보기` | `look` | 현재 방의 정보를 표시합니다 |
| `북/남/동/서` | `북` | 해당 방향으로 이동합니다 |
| `go`, `이동` | `go 북` | 지정한 방향으로 이동합니다 |
| `status`, `상태` | `status` | 캐릭터의 전체 상태를 표시합니다 |
| `inv`, `가방` | `inv` | 소지품 목록을 표시합니다 (최대 30칸) |
| `gold`, `돈` | `gold` | 현재 소지금을 표시합니다 (상한 99억) |

### ⚔️ 전투
| 명령어 | 예시 | 설명 |
|--------|------|------|
| `attack`, `공격` | `attack 도적` | 대상을 기본 공격합니다 |
| `cast`, `무공` | `cast 벽력검법` | 배운 무공을 시전합니다 |
| `meditate`, `수련` | `meditate` | 내공을 운행하여 MP를 회복합니다 |
| `arts`, `무공목록` | `arts` | 배운 무공 목록을 표시합니다 |

### 🎒 장비 (13슬롯)
| 명령어 | 예시 | 설명 |
|--------|------|------|
| `equip`, `장착` | `equip 철검` | 아이템을 해당 슬롯에 장착합니다 |
| `unequip`, `해제` | `unequip 철검` | 장착 중인 아이템을 해제합니다 |
| `eq`, `장비` | `eq` | 13슬롯 장비 현황과 총합 스탯을 표시합니다 |

### 🧪 아이템/소모품
| 명령어 | 예시 | 설명 |
|--------|------|------|
| `use`, `사용` | `use 소HP회복약` | 소모성 아이템을 사용합니다 |
| `sell`, `판매` | `sell 철검` | 아이템을 반값에 판매합니다 |
| `buy`, `구매` | `buy 철검` | 상점에서 아이템을 구매합니다 |
| `shop`, `상점` | `shop` | 현재 방의 상점 물품을 확인합니다 |
| `dismantle`, `분해` | `dismantle 철검` | 아이템을 분해하여 강화석을 얻습니다 |
| `discard`, `버리기` | `discard 깃털` | 아이템을 버립니다 |

### ✨ 강화
| 명령어 | 예시 | 설명 |
|--------|------|------|
| `enchant`, `강화` | `enchant 철검` | 강화석을 소모하여 +1~+15 강화 |
| `enchant -p`, `강화 -보호` | `enchant 철검 -p` | 보호석 사용 (실패 시 레벨 유지) |
| `enchant -a`, `강화 -고급` | `enchant 철검 -a` | 고급강화석 사용 (성공률 +20%) |
> **인챈트 재료는 모든 몬스터가 드랍합니다!** 레벨이 높을수록 드랍률이 올라갑니다.

### 🏠 귀환

| `return_go`, `귀환` | `return_go` | 귀환서를 사용하여 지정 장소로 이동합니다 |
