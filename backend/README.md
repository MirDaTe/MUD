# ⚔️ 낙화검심 (Nakhwa Geomshim) v0.6.2

> **밸런스 대격변** — 레벨제 장비·현실 경제·몬스터 재배치

무협 텍스트 기반 MMORPG 백엔드 서버입니다. FastAPI + SQLAlchemy + SQLite 기반의 REST API & WebSocket 실시간 게임 시스템.

## ⌨️ 명령어

### 기본 / 전투
`look/보기`, `북/남/동/서`, `status/상태`, `inv/가방`, `gold/돈`  
`attack/공격`, `cast/무공`, `meditate/수련`, `arts/무공목록`

### 장비 (13슬롯) 🔒 레벨 제한 있음
`equip/장착 아이템명`, `unequip/해제`, `eq/장비`

### 아이템 / 소모품
`use/사용`, `sell/판매`, `buy/구매`, `shop/상점`, `dismantle/분해`, `discard/버리기`

### 귀환
`return_set/귀환지정` (여관에서), `return_go/귀환` (귀환서 사용)

### 강화 (+1~+15)
`enchant/강화 아이템`, `enchant -p` (보호석), `enchant -a` (고급강화석)  
> 인챈트 재료는 모든 몬스터가 드랍! (레벨↑ 확률↑: 최대 30%/15%/8%)

### 문파
`guild_create/문파생성`, `guild_join/문파가입`, `guild_approve/승인`, `guild_leave/탈퇴`, `guild_kick/추방`, `guild_rank/계급`, `guild_info/문파`, `guild_storage/문파창고`, `guild_deposit/보관`, `guild_withdraw/인출`, `guild_gold_add/입금`, `guild_gold_out/출금`

### 관리자
`admin_set`, `admin_tp/순간이동`, `admin_give/아이템지급`, `admin_give_code/아이템코드지급`, `admin_users/유저목록`, `admin_chars/캐릭터목록`, `admin_rooms/방목록`, `admin_items/아이템목록`, `admin_item_info/아이템정보`, `admin_god/무적`
